외부에 공개된 웹 대시보드이 프로젝트에 존재하지 않음(로그인, 다중 사용자, 외부 접근 가능한 웹 서비스 등). 혼동 방지: handoff_webui.py가 띄우는 로컬 전용 Web UI MVP(127.0.0.1 바인딩, 인증 없음, 단일 사용자)는 존재하며 이 재설계의 실제 구현체다 — CLI Reference § Web UI (MVP) 참고. 이 줄은 "브라우저 UI 자체가 없다"고 잘못 읽힐 수 있어 2026-08-04 갱신.
다크모드 강제 시스템 연동tkinter 기본 테마는 OS 네이티브를 따르고 앱이 별도 라이트/다크 토큰을 구현하지 않음 — 이 문서(디자인 캔버스) 자체의 테마 토글과는 별개.
메시지 본문 전체 마크다운 렌더링2026-08-04 인터뷰로 코드블록만 지원(DEC-03)하기로 결정 — 제목·목록·굵게 등 전체 마크다운은 범위 밖.
API 키 직접 호출 아키텍처(세션 재개, 이벤트 파싱 재설계)§14는 API 키를 입력받는 화면만 설계 — 그 뒤에서 실제로 어떻게 provider를 호출할지는 다루지 않음(CFL-12, 별도 아키텍처 논의 필요).
Gemini 외 추가 AI 모델의 화면·컴포넌트요구사항이 "그 외 모델 추가는 문서로 남겨둘 것"으로 명시 — provider-extensibility.md에 일반화된 절차만 문서화하고 이 컴포넌트 라이브러리에는 넣지 않음.
