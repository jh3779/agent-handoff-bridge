포커스 시각화키보드 포커스가 항상 시각적으로 구분됨OS 네이티브 ttk 포커스 링에 의존 — 별도 커스텀 없음
아이콘 단독 버튼접근성 이름 필수해당 없음 — 모든 버튼이 텍스트 라벨을 가짐(아이콘 전용 버튼 없음)
색 대비텍스트 4.5:1 이상Bridge Indigo 라이트/다크 모두 WCAG AA 목표로 조정. 실제 tkinter 앱은 OS 테마 상속 — 이 문서의 색 토큰은 제안이지 현재 구현 값이 아님
오류 위치오류는 토스트가 아니라 필드/행동에 인접messagebox 모달로 항상 표시 — 토스트 없음(부합). 단, provider 실행 실패는 모달이 아니라 로그 append(의도적, S2 참조)
로그 가독성결과를 선택·복사 가능해야 함ScrolledText는 기본적으로 텍스트 선택/복사 가능 — 부합
상태 이중 부호화색만으로 상태 구분 금지현재는 색 배지 자체가 없고 텍스트 문장으로만 표시되어 오히려 이중부호화는 자연히 지켜짐 — 배지를 도입할 경우 아이콘+텍스트 필수(컴포넌트 §3)
